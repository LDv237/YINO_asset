# 两种执行语义：抽象做市 vs 现货

## 1. 为什么保留两套

数据源是 Binance 现货，抽象 `Simulator` 允许负仓位/负现金，适合从零库存跑双边做市，但不代表现货账户。本次主结果采用交付版本的 15 分钟现货 live run `20261021T162501Z-9821`；3049 抽象做市仅作为执行语义对照。

| 变体 | 配置 | 语义 | 本次用途 |
|---|---|---|---|
| 现货 | `config/spot_long_only.toml`，`allow_short=false`，`initial_cash_usd=10000` | 不允许裸卖；卖出数量不超过持仓；买入受 USDT 现金限制 | **主结果**：交付版本 15 分钟 live，0 负仓位/0 负现金 |
| 抽象做市 | `config/default.toml`，`allow_short=true`，`initial_cash_usd=0` | 带符号记账，允许负仓/负现金；从零库存运行双边做市 | 执行语义对照；3049 摘要 + Release 完整 run |

两者用的是同一套行情、因子、WAL、回放和验证代码，只换执行语义。

## 2. 现货变体的实现

### 2.1 策略层

`MarketMaker` 在 `allow_short=false` 时，`position <= 0` 就不发 ask，只保留 bid；`position > 0` 时，ask 数量取 `min(常规报价量, position)`，向下取整到 1e-8。买入报价照发，但能不能成交由模拟器的现金约束决定。

### 2.2 执行层

`Simulator` 在 `allow_short=false` 时卖出最大数量就是当前持仓，`position` 不会变成负数；买入最大数量受 `cash / (price * (1 + fee_rate))` 限制，现金不会变成负数。每个 symbol 的初始 USDT 现金是 `initial_cash_usd`，这个变体取 10,000。借币、保证金、强平、资金费率都没有建模。

### 2.3 一个自然的后果

从零基础币库存起步，做市商一开始只能买、不能卖，只有买到库存后才会出现 ask。某些交易对在 15 分钟内可能一直等不到买入成交，所以 `fills=0`、`position=0` 是可能也合理的结果；主结果里 6 个 symbol 都有成交。

## 3. 运行方式

```bash
# 主结果：现货
python -m tickforge live --config config/spot_long_only.toml --duration 900 --out artifacts

# 抽象做市对照
python -m tickforge live --config config/default.toml --duration 900 --out artifacts
```

回放与校验对两个变体完全一样：

```bash
python -m tickforge verify --run <run_dir>
python -m tickforge replay --run <run_dir> --out <run_dir>-replay --verify
```

### 4.3 严格落盘版（spot long-only + fsync always）

`config/spot_long_only_durable.toml` 只把 WAL 改成 `fsync_policy="always"`，其余现货约束不变。6db8 运行 900.172 s：272,784 帧 / 272,802 条 WAL（18 快照），37,802 信号 / 1,578 fills，0 负仓位/负现金；p50/p99/p999 3.444/5.793/9.742 ms。网络缺口边界见 `交付说明.md` §6；`verify`/`replay --verify` 通过。

该配置用于严格持久化的取舍对照；`interval` 配置仍是主结果的性能与语义基准；gap 是交易所侧未送到的数据，不是 WAL 丢帧。

### 4.4 结论

主结果是交付版本的现货 live run：650,532 帧、6,437 fills、所有 symbol position/cash ≥ 0、0 丢失、0 gap、回放一致。3049 抽象做市只作为执行语义对照，允许负仓位/负现金，不代表现货账户；3049 与 9821 的对比不以收益为目标，评价重点是语义正确和链路可复现。

## 5. 解释与局限

- 抽象做市版不是现货账户，允许负仓位是刻意选择，用于从零库存跑双边做市；不能据此声称现货可做空。
- 主结果现货版也不是真实账户：没有真实下单、订单队列、撤单延迟、借币、保证金、交易所风控。
- 现货版每 symbol 初始 10,000 USDT 是人为设置的模拟资金；不同初始资金会影响 fills 和 PnL。
- 成交判断使用基于实际成交时间 `T` 的 quote-time guard：`T` 早于报价时不会成交。15 分钟对照 run 的执行结果由同一份 WAL 按该规则与 tick 取整重算，延迟和资源数据仍来自原始 live 采集。主结果 9821 的成交、延迟和资源数据均来自同一次 live，不涉及重算。
- 两个版本都不以收益为评价目标；比较重点是仓位/现金约束、信号行为、回放确定性。
- 性能数据以主结果 9821 为准；3049 抽象版仅作为执行语义与链路对照，其负仓位属于抽象记账语义，与现货约束无关。
