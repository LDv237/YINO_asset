## 4. 完整性口径

主结果的 `summary.json` / `manifest.json` 记录计数、WAL CRC/seq、分段 SHA-256 和三个 derived 文件的 SHA-256。`verify` 校验 WAL 和 manifest；`replay --verify` 重算三个派生文件并与运行目录对比。历史 run 的执行结果是同一份 WAL 用实际成交时间 `T` 的 quote-time guard + tick 取整重算的，延迟/资源/健康仍是原 live；主结果 3049 是 live 单源，不适用重算口径。
