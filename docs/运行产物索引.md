# 运行产物索引

正式运行目录与附件按用途分类存放，避免把历史实验、日志和交付文件混在一起。

## 1. 目录分类

| 目录 | 内容 |
|---|---|
| `artifacts/runs/` | 每次运行的完整目录（WAL、derived、日志、summary、manifest、replay） |
| `artifacts/exports/` | 正式运行的 WAL 压缩包、JSONL、CSV 压缩包 |
| `artifacts/summaries/` | 正式运行与变体运行的摘要、清单、成交 CSV |
| `artifacts/evidence/` | 成交编号、现金最低值、交易活跃度、崩溃恢复等验证证据 |
| `artifacts/logs/` | 控制台日志与健康快照 |
| `artifacts/experiments/` | fsync 对照、旧 smoke、同一 WAL 变体等实验 |
| `交付材料/` | 面向面试官的干净附件副本与材料索引（不进入 Git） |

  raw/                     2 个 WAL 分段，388,394 条记录

  logs/tickforge.log       结构化运行日志
