## 3. 复现入口

环境：Python 3.14.7；依赖由 `requirements-lock.txt` 固定。

```bash
python -m pip install -r requirements-lock.txt

# 15 分钟实时运行（抽象做市性能基准）
python -m tickforge live --config config/default.toml --duration 900 --out artifacts

# 回放与校验
python -m tickforge verify --run artifacts/runs/<run_id>
python -m tickforge replay --run artifacts/runs/<run_id> --verify

# 离线样本（无需交易所网络）
python -m tickforge replay --run samples/demo_run --verify
```

| 项目 | 结果 |
|---|---|
| 正式性能基准 | 抽象做市 / interval，`20261020T072820Z-53b5`，900.116 s，388,388 帧，43,309 信号，10,066 fills |
| 端到端延迟 | p50 0.512 ms / p99 2.435 ms / p999 27.554 ms |
| 数据完整性 | 收到的原始帧 0 丢失；WAL CRC/seq/分段 SHA-256 通过 |
| 回放确定性 | factors / signals / fills 三个 SHA-256 与实时一致 |
| 现货只做多 | `20261020T074416Z-91ac`，325,280 帧，2,131 fills，0 负仓位/负现金 |
| 严格落盘 | `20261020T082850Z-6db8`，272,784 帧，272,802 次 fsync，1,576 fills，0 负仓位/负现金 |
| 异常终止恢复 | 强制终止后 WAL 229 条已 fsync 记录 CRC/seq 有效，无残缺尾部 |
| 测试 | 259 passed, 0 failed |
| 交易活跃度 | 正式窗口所在 07:00–08:00 UTC 桶成交额 73.96M USDT、125,770 笔，47 个完整小时中排名 3/47；严格版所在 08:00–09:00 UTC 桶排名 4/47 |

## 6. 已知边界

- **Docker**：`Dockerfile`/compose 与验证脚本已提供；本机 Docker Desktop 已安装，但 WSL2 虚拟化组件不完整、引擎无法启动，因此镜像尚未在本机构建/运行。该缺口在 `docs/Docker构建验证.md` 中有完整的验收命令和证据清单。
- **持久化**：正式性能基准使用 `interval`（每 250ms 尝试组提交），崩溃时未同步尾部可能丢失，250ms 不是硬上界；严格版使用 `always`，应用层每条 fsync 后才处理，不构成对物理介质的绝对保证。
- **行情粒度**：成交流使用 `@aggTrade`（交易所聚合），不是每一笔底层 fill；成交量类因子足够，逐笔微观结构需要切 `@trade`。
- **模拟执行**：`Simulator` 是信号到成交的抽象记账器；抽象版允许负仓位，现货只做多版会限制裸卖与现金；两者都不是真实交易所账户。
- 策略只用于验证完整链路，不评价收益；6 个交易对是为制造真实负载，BTCUSDT 始终在列。
