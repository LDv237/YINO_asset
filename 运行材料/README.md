# 运行材料目录

这个目录放真实运行数据、验证证据、日志和复现入口，不是第二份交付说明。总提交说明、材料清单和实测摘要看包根目录的 [`../交付说明.md`](../交付说明.md)。

## 建议阅读顺序

优先看 [`07_最终代码单源复跑/`](07_最终代码单源复跑/)：最终代码的单源 15 分钟 run；[`02_正式运行/`](02_正式运行/) 是历史性能基准。

1. [`材料索引.md`](材料索引.md)：本目录每个文件放的是什么；
2. [`复现入口.md`](复现入口.md)：完整 Release、分类附件、离线样本三条复现命令；
3. [`07_最终代码单源复跑/`](07_最终代码单源复跑/)：最终代码 15 分钟单源 run 的摘要、WAL、derived、日志和回放摘要（主结果）；
4. [`02_正式运行/`](02_正式运行/)：53b5 历史基准的摘要、原始 WAL、derived、JSONL、CSV；
5. [`03_执行变体/`](03_执行变体/)：只做多 interval、同一 WAL 对照、严格落盘的摘要与成交 CSV；
6. [`04_验证证据/`](04_验证证据/)：成交编号、现金最低值、交易活跃度、崩溃恢复、健康状态；
7. [`05_运行日志/`](05_运行日志/)：正式运行、只做多、严格版和最终单源 run 的控制台日志。

代码、文档、配置和离线样本在包根目录；单独代码包 `代码包.zip` 是仓库根目录/邮件外层的另一个文件，不在本目录里。
