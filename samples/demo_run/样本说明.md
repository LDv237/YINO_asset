# TickForge 离线样本说明

本样本截取自历史基准 53b5 的前 20,000 条 WAL 记录（约 64.884 秒），仅用于在不访问交易所网络的条件下验证 replay 机制。本次提交的主结果为 `运行材料/01_主结果_现货_9821/`。

## 回放与验证

```bash
python -m tickforge replay --run samples/demo_run \
  --out samples/demo_run-replay --verify
```

预期：`deterministic=true`、`verified=true`，因子、信号、成交三个 SHA-256 一致。

注意：

- 样本只支持 `replay --verify`，不支持 `tickforge verify`（样本没有完整 run 的 `manifest.json` 和 `reconciliation`）；
- 执行时需显式指定 `--out`；否则默认输出目录在第二次执行时会因非空而拒绝覆盖。

## 文件

```text
raw/raw-000001.wal   原始 WAL 分段（二进制，含 WS 帧与 REST 快照）
config.json          样本回放使用的配置
summary.json         样本离线回放生成的参考摘要
sample_manifest.json 样本来源和 WAL 分段信息
```

`summary.json` 是离线回放参考摘要，不是 live 行情运行结果。正式主结果和 replay 对照在 `运行材料/01_主结果_现货_9821/`；53b5 的完整 WAL/JSONL/CSV 在 GitHub Release。

## 重新导出可读格式

样本压缩包不包含 CSV/JSONL 便利视图；如需这些视图，可从 WAL 重新导出：

```bash
python tools/wal_export.py --run samples/demo_run --out samples/demo_run/raw_events.jsonl.gz
python tools/wal_export_csv.py --run samples/demo_run --out-dir samples/demo_run/csv
```
