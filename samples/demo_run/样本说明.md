# TickForge 离线样本说明

这个样本是我从正式运行 `artifacts/runs/20261020T072820Z-53b5` 里截的前 20,000 条 WAL 记录，大约 64.884 秒。我做这个样本，是为了让人不访问交易所网络也能把完整回放和校验流程走一遍。

## 回放与验证

拿到样本后直接跑：

```bash
python -m tickforge replay --run samples/demo_run --verify
```

预期结果是 `deterministic=true`、`verified=true`，因子、信号、成交三个摘要全部一致。

这里要说明一下：这个目录的 `summary.json` 是样本离线回放生成的参考摘要，不是 live 行情运行结果，生成工具是 `tools/make_sample_reference.py`。正式 15 分钟 live 和 replay 的对照证据在：

```text
artifacts/runs/20261020T072820Z-53b5/replay/replay_summary.json
```

## 原始行情

```text
raw/raw-000001.wal          原始 WAL 分段（二进制，含 WS 帧与 REST 快照）
raw_events.jsonl.gz         20,000 条记录的人类可读 JSONL 导出
```

`raw/` 里是原始 WAL，`raw_events.jsonl.gz` 是从 WAL 导出的可读版本。

## 快速查看文件

不想解压的话，直接看这两个文件：

```text
raw_events_head.jsonl        前 100 行 JSONL
raw_events_head.pretty.json  前 3 条记录的格式化版本
```

用文本编辑器就能打开。

## CSV 视图

CSV 是按事件类型导出的表格视图，行数是这些：

```text
csv/agg_trades.csv          1,074 行
csv/book_ticker.csv         16,021 行
csv/depth_updates.csv       2,899 行
csv/snapshots.csv           6 行
```

字段说明在 `csv/字段说明.md`。启动阶段快照到达之前的 depth 行，`best_bid/ask` 是空的，属于正常现象。

## 重新生成样本

想自己重新裁一份，命令是：

```bash
python tools/trim_run.py --run artifacts/runs/20261020T072820Z-53b5 \
  --out samples/demo_run --records 20000
python tools/make_sample_reference.py --sample samples/demo_run
```

生成完再跑一次上面的 `replay --verify`，看摘要能不能对上。
