# TickForge 离线样本说明

本目录从正式运行 `artifacts/runs/20261020T072820Z-53b5` 中截取前 20,000 条 WAL 记录（约 64.884 秒），用于在**不访问交易所网络**的情况下复现完整回放与校验流程。

## 回放与验证

```bash
python -m tickforge replay --run samples/demo_run --verify
```

预期结果：

- `deterministic=true`
- `verified=true`
- 因子 / 信号 / 成交三个摘要全部一致

本目录的 `summary.json` 是由本样本离线回放生成的**参考摘要**，不是 live 行情运行结果；生成工具为 `tools/make_sample_reference.py`。正式 15 分钟 live-vs-replay 的证据在：

```text
artifacts/runs/20261020T072820Z-53b5/replay/replay_summary.json
```

raw/raw-000001.wal          原始 WAL 分段（二进制，含 WS 帧与 REST 快照）

这两个文件无需解压，可直接用文本编辑器打开。

## 重新生成样本

```bash
python tools/trim_run.py --run artifacts/runs/20261020T072820Z-53b5 \
  --out samples/demo_run --records 20000
python tools/make_sample_reference.py --sample samples/demo_run
```

重新生成后，可再次执行上面的 `replay --verify` 检查摘要是否一致。
