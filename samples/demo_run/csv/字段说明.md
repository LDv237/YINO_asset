# CSV 视图说明（离线样本）

这些 CSV 是 `samples/demo_run` 前 20,000 条 WAL 记录的表格视图，权威原始数据还是 WAL。

| 文件 | 行数 | 说明 |
|---|---:|---|
| `agg_trades.csv` | 1,074 | 交易所聚合成交 |
| `book_ticker.csv` | 16,021 | 最优买/卖档更新 |
| `depth_updates.csv` | 2,899 | diff depth 事件，含重建后的 best bid/ask |
| `snapshots.csv` | 6 | REST 快照元数据 |

字段含义和正式运行一样，`seq` 可以拿去和 `../raw_events.jsonl.gz` 对照。启动时快照到达之前的 depth 行，`best_bid/ask` 为空，属正常现象。
